# Findings: oMLX GBNF / structured_outputs — 2026-09-03

Branch: `cursor/maple-gbnf-no-needle`. Live probe against oMLX `:8000` + Maple Preview.

## Support

oMLX **does** enforce grammar-constrained decoding (xgrammar). Confirmed by forcing
output to the unlikely token `ZQX` while the user prompt asked for a weather sentence.

## How to pass the format

| Request field | Enforced? | Notes |
|---|---|---|
| `structured_outputs.grammar` | **yes** | Preferred; EBNF/GBNF-style `root ::= …` |
| `structured_outputs.regex` | yes | |
| `structured_outputs.choice` | yes | |
| `structured_outputs.json` | yes | JSON schema |
| `guided_grammar` | **yes** | Alias; also enforced |
| Top-level `grammar` | **no** | Ignored (free prose) |

Probe script: `scripts/probe_omlx_gbnf.py`.

## evprtr implication

Harness → compositor should **passthrough** `structured_outputs` / `guided_grammar` /
`response_format` to upstream. Do not invent grammar from `tools` in the first cut
(oMLX may not auto-install tool grammars from `tools` alone).

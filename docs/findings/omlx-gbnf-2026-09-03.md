## Support

oMLX **does** enforce grammar-constrained decoding (xgrammar). Confirmed by forcing
output to the unlikely token `ZQX` while the user prompt asked for a weather sentence.

## evprtr implication

Harness → compositor should **passthrough** `structured_outputs` / `guided_grammar` /
`response_format` to upstream.

### tools → structured_outputs (Needle-off)

oMLX does **not** reliably install a tool-name grammar from `tools` alone. With
`tools` + `structured_outputs.json` (`oneOf` per tool: `name` const + `arguments`
schema), Maple returns the call as assistant **content** JSON and
`tool_calls: null`.

Compositor path (`EVPRTR_NEEDLE_ENABLED=0`, `EVPRTR_TOOLS_GRAMMAR=1` default):

1. `attach_tools_structured_outputs` — inject schema when Needle is off and the
   harness did not already set `structured_outputs` / `guided_grammar`; skip when
   `tool_choice=none`.
2. `promote_tool_json_content` — lift content JSON → OpenAI `tool_calls`.

Module: `compositor/tools/tools_grammar.py`.
